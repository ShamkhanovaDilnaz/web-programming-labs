# Лабораторные работы 1–8

Откройте папку `labs` в VS Code. Для просмотра откройте `index.html` в браузере и выберите работу.

- `index.html` — №1: базовая структура проекта.
- `lab2.html` — №2: семантическое резюме и контактная форма.
- `lab3.html` — №3: форма из трёх шагов с HTML5-валидацией.
- `lab4.html` — №4: оформление резюме внешним CSS и шрифтом Google Fonts.
- `lab5.html` — №5: каталог товаров на Grid и Flexbox.
- `lab6.html` — №6: адаптивный каталог для телефона, планшета и монитора.
- `lab7.html` — №7: список задач с добавлением, выполнением и удалением.
- `lab8.html` — №8: проверка email, пароля и телефона регулярными выражениями.

Общие стили находятся в `styles/main.css`, обработчики — в `js/app.js` и `js/lab8.js`. Для Google Fonts нужен интернет; без него используется Arial. Формы учебные: данные проверяются, но не отправляются на сервер.
